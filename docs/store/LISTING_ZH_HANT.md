## 應用程式名稱（上限 30 字元）

```
Chat Report 聊天關係分析
```
> 20 字元。⚠️ **不要寫 "WhatsApp"** —— 屬他人商標，Play 會以商標侵權駁回。

---

## 簡短說明（上限 80 字元）

```
匯入聊天紀錄，30 秒產生一份 AI 關係分析報告。本機解析，用完即刪。
```
> 34 字元。

## 完整說明（上限 4000 字元）

```
你們的對話，到底說明了什麼？

Chat Report 把一份匯出的聊天紀錄，變成一份關於這段關係的真報告——不是星座式的泛泛而談，而是每個數字都能追溯回真實訊息。

你會看到什麼

• 關係溫度分——0 到 100 的一個數字，概括這段關係此刻的狀態
• 互動平衡——誰傳得更多、誰更常開啟話題、各自的回覆速度
• 情緒曲線——逐月走勢，自動標出最暖的月份和那段低谷
• 話題分布——你們真正常聊的五件事，依占比排序
• 聊天人格——從真實習慣裡提煉的標籤，各三個
• 深度解讀——一篇長文，講你們的相處節奏、轉折點，以及各自在意的東西，附原文金句與日期

每個數字都有出處

訊息則數、回覆時間、誰先開口——所有統計都在你的手機上，從你自己的匯出檔案算出。AI 只負責解讀這些數字和對話內容，絕不憑空編造。引用的金句都附上日期，你可以自己回去核對。

隱私優先

• 聊天檔案的解析與統計全程在裝置本機完成
• 為了產生報告，聊天文字會經加密連線傳送給 AI 服務商——分析前先徵求你的同意，我們不保存
• 我們的伺服器不保存任何內容，也不需要註冊帳號
• 分享報告卡片時，姓名會自動縮寫為首字母，且無法關閉

怎麼用

1. 開啟你的聊天軟體，把某段對話匯出為 .txt 檔案（選「不含媒體檔案」）
2. 開啟 Chat Report 選取該檔案——應用程式會一步步引導你
3. 選擇哪一個是你，以及這段關係的類型
4. 約 30 秒後拿到報告

趕時間？直接把一段對話貼進應用程式，就能免費快讀。

適合誰

好奇彼此相處節奏的情侶。想讀懂曖昧期的人。想為一堆內部梗做年度回顧的好友。以及，正在回望某個已經結束的篇章的人。

關於它不是什麼

Chat Report 描述的是一段對話裡的模式。它不是心理治療，不是診斷，也不是對任何人的評判。把它當成一面值得聊聊的鏡子，而不是一張計分卡。

Chat Report 與任何訊息服務均無從屬、認可或關聯關係。
```
> ~860 字元，餘量充足。最後一行免責聲明與「不是治療／診斷」段落**必須保留**。

## Play Console 語言代碼

繁體中文在 Play Console 分成兩個獨立語言，**兩者不會互相回退**：

| 語言 | 代碼 | 市場 |
|---|---|---|
| 中文（繁體） | `zh-TW` | 台灣 |
| 中文（香港） | `zh-HK` | 香港 —— **WhatsApp 重點市場** |

本文案兩者皆適用，用詞已刻意避開只在單一地區通行的說法。建議**兩個都建**：
在 Play Console 逐一新增後，同一份文案貼兩次即可。若只建其中一個，另一地區的使用者
會看到英文（預設語言）頁面。
