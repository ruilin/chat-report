## 完整说明（上限 4000 字符）

```
你们的聊天，到底说明了什么？

Chat Report 把一份导出的聊天记录，变成一份关于这段关系的真报告——不是星座式的泛泛而谈，而是每个数字都能追溯回真实消息。

你会看到什么

• 关系温度分——0 到 100 的一个数字，概括这段关系此刻的状态
• 互动平衡——谁发得更多、谁更常开启对话、各自的回复速度
• 情绪曲线——逐月走势，自动标出最暖的月份和那段低谷
• 话题分布——你们真正常聊的五件事，按占比排序
• 聊天人格——从真实习惯里提炼的标签，各三个
• 深度解读——一篇长文，讲你们的相处节奏、转折点、以及各自在意的东西，附原文金句与日期

每个数字都有出处

消息条数、回复时长、谁先开口——所有统计都在你的手机上从你自己的导出文件算出。AI 只负责解读这些数字和对话内容，绝不凭空编造。引用的金句都带日期，你可以自己回去核对。

隐私优先

• 聊天文件的解析与统计全程在设备本地完成
• 为了生成报告，聊天文字会经加密连接发送给 AI 服务商——分析前先征求你的同意，我们不保存
• 我们的服务器不保存任何内容，也不需要注册账号
• 分享报告卡片时，姓名会自动缩写为首字母，且无法关闭

怎么用

1. 打开你的聊天软件，把某段对话导出为 .txt 文件（选「不含媒体文件」）
2. 打开 Chat Report 选中该文件——应用会一步步引导你
3. 选择哪个是你，以及这段关系的类型
4. 约 30 秒后拿到报告

赶时间？直接把一段对话粘贴进应用，就能免费快读。

还没想好？在应用里先看一份示例报告，不用导出就知道会得到什么。

适合谁

好奇彼此相处节奏的情侣。想读懂暧昧期的人。想给一堆内部梗做年度回顾的好友。以及，正在回望某个已经结束的章节的人。

关于它不是什么

Chat Report 描述的是一段对话里的模式。它不是心理治疗，不是诊断，也不是对任何人的评判。把它当成一面值得聊聊的镜子，而不是一张记分卡。

Chat Report 与任何消息服务均无从属、认可或关联关系。
```
> ~880 字符，余量充足。最后一行免责声明与"不是治疗/诊断"段落**必须保留**。

## 关于繁体中文（zh-TW / zh-HK）

**香港是 WhatsApp 的重点市场**，值得单独加一个繁体版商店页。但请注意：
繁体版**不是简转繁字符替换那么简单**，用词习惯有差异（如「信息」→「訊息」、
「视频」→「影片」、「应用」→「應用程式」）。建议找母语者过一遍，别用工具直转。
